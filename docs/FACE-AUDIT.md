# Face generator audit

Generated by `node tests/face-audit.mjs 2000 300` (generator version 2). Do not edit by hand.

**Result: PASS** — 2000 deterministic profiles validated; 300 morphed through the head asset for target checks.

## What is checked

- Every profile is deterministic (same seed → identical record), uses only catalogue values, keeps every shape value in [-1, 1], ages 18–30, and never places a beauty mark on the eyes or lips.
- Every hairstyle suits the face's natural hair texture.
- The queue (`src/face/queue.js`) never shows the same complete face twice in a row, and its state survives a JSON save/load.
- For the geometry sample: finite vertices, symmetric eyes, open eyelids (lash lines apart) and a usable mouth on every face.

## Variety

- Distinct face signatures (origin · presentation · hairstyle · hair colour · iris · tone band · brow shape) seen in 2000 faces: **1901**. This is a lower bound on visibly different configurations; it ignores the 93 continuous shape dimensions, freckles, marks and lip/brow detail that also differ per face. It is not a "millions of faces" claim.
- Queue neighbours: 0 identical, 0.1% same hairstyle, 0.1% same main origin, 1.5% same skin-tone band; 0 signature repeats within four faces.
- Freckles 15.8%, beauty marks 49.0%, vitiligo 2.0%, albinism 0.9%, dyed hair 8.0%, highlights 9.2%, head coverings 8.1%.
