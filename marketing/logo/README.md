# Game logo

Option A, "Sticker Pop" (owner's pick, 21 October 2026), for game platforms and portals: the name mark shown with
the game's listing, banners and loading screens. It is separate from the thumbnail art.

| File | Use |
|------|-----|
| `freestyle-makeup-logo.svg` | The master: vector, lettering converted to outlines (no font needed), any size |
| `freestyle-makeup-logo-2048.png` | 2048 × 857, transparent background |
| `freestyle-makeup-logo-1024.png` | 1024 × 429, transparent background |
| `freestyle-makeup-logo-512.png` | 512 × 214, transparent background |

- **Colours** (from the game): rose `#ff7aa8` (glossy, `#ffb3cd` to `#ee4d88`), ink `#2a1d15`, gold `#ffb627`, and
  a white sticker edge so it stays readable on dark, light or busy backgrounds.
- **Lettering:** Fredoka Bold (SIL Open Font License 1.1, `licenses/fredoka-OFL.txt`; recorded in `ASSETS.md`).
- **Name:** "Freestyle Makeup" is the working title. If the title changes, regenerate the lettering at the same
  sizes and positions.
- **Clear space:** keep at least the height of the sparkle (about a tenth of the logo's height) clear around it.
  Don't stretch, recolour or put it in a box.
