# Game logo

"Freestyle ASMR Makeup Artist" in the Sticker Pop style (owner's pick of both, 21 October 2026), for game platforms
and portals: the name mark shown with the game's listing, banners and loading screens. It is separate from the
thumbnail art.

| File | Use |
|------|-----|
| `freestyle-asmr-makeup-artist-logo.svg` | The master: vector, lettering converted to outlines (no font needed), any size |
| `freestyle-asmr-makeup-artist-logo-2048.png` | 2048 × 977, transparent background |
| `freestyle-asmr-makeup-artist-logo-1024.png` | 1024 × 489, transparent background |
| `freestyle-asmr-makeup-artist-logo-512.png` | 512 × 244, transparent background |

- **Colours** (from the game): rose `#ff7aa8` (glossy, `#ffb3cd` to `#ee4d88`), ink `#2a1d15`, gold `#ffb627`, and
  a white sticker edge so it stays readable on dark, light or busy backgrounds.
- **Lettering:** Fredoka Bold (SIL Open Font License 1.1, `licenses/fredoka-OFL.txt`; recorded in `ASSETS.md`).
- **Name:** "Freestyle ASMR Makeup Artist", chosen for search: "FREESTYLE" with "ASMR" on a gold sticker badge, the
  big glossy "MAKEUP", then "ARTIST" on an ink tag below.
- **Clear space:** keep at least the height of the sparkle (about a tenth of the logo's height) clear around it.
  Don't stretch, recolour or put it in a box.
