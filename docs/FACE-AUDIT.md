# Face generator audit

Generated by `node tests/face-audit.mjs 2000 300` (generator version 5). Do not edit by hand.

**Result: PASS** — 2000 deterministic profiles validated; 300 morphed through the head asset for target checks.

## What is checked

- Every profile is deterministic (same seed → identical record), uses only catalogue values, keeps every shape value in [-1, 1], ages 18–30, and never places a beauty mark on the eyes or lips.
- Every face is feminine, with natural (undyed) hair in a long style from the catalogue that suits her natural hair texture.
- Every outfit uses catalogue values; its colours come from the palette for the face's complexion; deeper skin (tone ≥ 0.45) never wears very dark colours (black, navy, charcoal, burgundy, plum); and the main colour is never close to the skin's own colour.
- The queue (`src/face/queue.js`) never shows the same complete face twice in a row, and its state survives a JSON save/load.
- For the geometry sample: finite vertices, symmetric eyes, open eyelids (lash lines apart) and a usable mouth on every face.

## Variety

- Distinct face signatures (origin · presentation · hairstyle · hair colour · iris · tone band · brow shape · parting · outfit colour) seen in 2000 faces: **1995**. This is a lower bound on visibly different configurations; it ignores the 93 continuous shape dimensions, freckles, marks and lip/brow detail that also differ per face. It is not a "millions of faces" claim.
- Queue neighbours: 0 identical, 0.4% same hairstyle, 0.0% same main origin, 1.1% same skin-tone band; 0 signature repeats within four faces.
- Freckles 12.3%, beauty marks 44.4%, subtle natural highlights 11.4%. Every face has long, visible hair (no short cuts, updos or head coverings), and no vitiligo, albinism or dyed colours (owner decisions).
